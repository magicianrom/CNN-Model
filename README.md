# CNN-Model-
Upload a facial image to predict the person's age.

## Project structure
```
notebooks/       CNN.ipynb
streamlit/      streamlit.py, runtime.txt, age_model.keras
```
| File | Purpose |
|---|---|
| `notebooks/CNN.ipynb` | Building the model with Neural Networks |
| `streamlit/age.py` | Streamlit app: upload a facial image to recieve its predicting lable |
| `streamlit/age_model.keras` | Final model used to classify the images during development |

## URL
https://agepredictor.streamlit.app
